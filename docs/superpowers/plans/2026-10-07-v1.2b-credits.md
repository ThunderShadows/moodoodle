# moodoodle v1.2 Plan B: Save with credit + Respect artists

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. TDD per task; steps use checkboxes.

**Goal:** Every keep records who made the image and what reuse is allowed, shown as a tile line and a reuse
badge, editable in a details panel, and written to `CREDITS.md` in every export. Honor NoAI opt-outs and
never bulk-collect from artist platforms.

**Architecture:** Pure functions in `src/lib/`. The **content script** reads page metadata for the kept
`<img>` (`extractPageCredit`: JSON-LD, `rel="license"`, author meta, NoAI meta). The **worker** reads the file's
XMP packet as text (`readXmp`; no DOMParser in service workers) and the `X-Robots-Tag` response header,
then `mergeCredit` combines everything by priority into `SavedImage.credit` (the field already exists from
Plan A's DB v3). The UI shows `creditLine` + `badgeFor(license)`; `Details.svelte` edits fields through
`applyUserEdit` (marks the source as `user`, so it's never overwritten). `buildZip` writes `CREDITS.md`.

**Spec:** `docs/specs/2026-10-07-boards-and-credits.md` §4–§6, §8, §10.

## Global Constraints
- Default badge is **Reference only**; never "reusable" without a stated CC0/PD/CC license.
- Badge rules: Free to reuse = cc0, public-domain, CC BY, CC BY-SA; Reuse with conditions = any NC/ND; Reference only = everything else.
- Priority: user > JSON-LD > XMP > rel-license > meta (creator only, `inferred`).
- NoAI if any of: page meta robots containing `noai`/`noimageai`; image response `X-Robots-Tag` containing either; XMP `plus:DataMining` value starting `DMI-PROHIBITED`.
- No bulk keep on pages with NoAI or on artstation.com, cara.app, deviantart.com, behance.net, dribbble.com (any subdomain). Single Keep is always allowed.
- XMP scan limited to the first 256 KB of the file.
- No new permissions; nothing new leaves the device.

## Review Focus
1. **Pages with several images in their JSON-LD**: only the entry matching the kept image (ignoring query strings) is used. Otherwise no credit.
2. **Malformed JSON-LD or XMP**: ignored; keep still succeeds (tests in Tasks 2 and 3).
3. **User-edited credit fields** survive a later re-keep or merge (Task 4).
4. **Unknown license** must show "Reference only", never "Free to reuse" (Task 1).
5. **The bulk-keep block** is enforced in the worker too, not just in the popup UI (Task 6).

## Tasks

### Task 1: License parsing and badges (`src/lib/license.ts`)
- `parseLicense(input?: string): License`: CC licenses/<code>/<version>, publicdomain/zero → cc0, publicdomain/mark → public-domain, "©" or "all rights reserved" text → all-rights-reserved (notice kept), else unknown(raw).
- `badgeFor(l) → 'reuse' | 'conditions' | 'reference'`; `BADGE_LABEL`; `licenseLabel(l)` ("CC BY 4.0", "CC0", "Public domain", "All rights reserved", "Not stated").
- Tests: each CC code/version, http/https/trailing slash, deed URLs, cc0, mark, © text, garbage → unknown → reference.

### Task 2: Page credit extraction (`src/lib/pagecredit.ts`, jsdom tests)
- `extractPageCredit(doc, imageUrl): PageCredit` where `PageCredit = { jsonLd?: Partial<Credit>; relLicense?: string; metaAuthor?: string; noAI: boolean }`.
- JSON-LD: every `script[type="application/ld+json"]`; walk objects, arrays and `@graph`; candidates are `ImageObject`s plus `image` values of other nodes; match `contentUrl`/`url`/string with the image URL ignoring query/hash; take `creator` (string | Person | Organization | array → names joined ", ", first url), `creditText`, `copyrightNotice`, `license`, `acquireLicensePage`, `name`.
- `rel-license`: first `a[rel~=license]`/`link[rel~=license]` href. Meta author: `meta[name=author]`, `meta[property="article:author"]`, `meta[name="twitter:creator"]`.
- NoAI: any `meta[name=robots|googlebot|...]` content matching /\bno(image)?ai\b/i.
- Tests: graph, array creator, mismatched image (no credit), malformed JSON (ignored), rel-license, meta, noai meta.

### Task 3: XMP reader (`src/lib/xmp.ts`)
- `readXmp(bytes: Uint8Array): XmpCredit | undefined` with `XmpCredit = { creator?; rights?; webStatement?; license?; noAI: boolean }`; decode the first 256 KB as latin1, find `<x:xmpmeta`…`</x:xmpmeta>`, and regex-read `dc:creator` (first `rdf:li`), `dc:rights` (first `rdf:li`), `xmpRights:WebStatement` (attribute or element), `cc:license` (`rdf:resource` attribute or element), `plus:DataMining` (attribute or element, value or URI).
- Tests: no packet → undefined; full packet; attribute form; DataMining prohibited → noAI; packet after 256 KB ignored.

### Task 4: Merge and edits (`src/lib/credit.ts`)
- `mergeCredit({ page?: PageCredit; xmp?: XmpCredit; headerNoAI?: boolean; previous?: Credit }): Credit`, applying the priority rules: fieldSources per field; confidence stated if any of JSON-LD/XMP/rel-license supplied a field, inferred if only meta, none otherwise; fields from `previous` with source `user` always win.
- `applyUserEdit(credit, patch: { creator?; creatorUrl?; license?: string; copyrightNotice? }): Credit`: parse the license text and mark the sources `user`.
- `creditLine(credit, image) → string | undefined` ("“Title” by X, CC BY 4.0" only when creator and license are both known).
- `parseRobots(header?: string): boolean`.
- Tests: the priority table, inferred vs stated, previous user fields preserved, edit marks user, creditLine only when both known.

### Task 5: Wire credits into keeping
- Types: `Message` keep gains `pageCredit?: PageCredit`; keep-many gains `pageCredits?: Record<string, PageCredit>`; new `{ type: 'credit-for'; imageUrl }`. `collect-images` returns `{ urls, credits, noAI }`.
- `KeepDeps.fetchBlob` becomes `fetchImage(url) → { blob, robots?: string }` (`decode.ts` reads `X-Robots-Tag`).
- `keepImage` gains `input.pageCredit`, then reads XMP from the blob and stores `mergeCredit(...)`.
- Content script: `extractPageCredit(document, src)` on Keep; answers `credit-for` and the new `collect-images` shape. Worker: the context-menu keep asks the tab with `credit-for` (fallback: none). Popup: sends `pageCredits` with keep-many.
- `ImageStore.setCredit(id, credit)`.
- Tests: keep stores the merged credit (page JSON-LD + XMP blob); a header noai sets noAI; setCredit persists.

### Task 6: Respect artists (`src/lib/respect.ts`)
- `isArtistPlatform(url)`, `bulkKeepBlocked(pageUrl, pageNoAI)`. Popup: if blocked, the Keep-all card shows "Artists here asked not to be collected in bulk. Keep the ones you love one at a time." with no button. The worker refuses `keep-many` when blocked (`{ kept: 0, skipped: n, blocked: true }`); `KeepManyResult.blocked?`.
- Tests: domains + subdomains, lookalike domains (`notcara.app`) not blocked, worker-level refusal via keepMany guard.

### Task 7: Credit UI
- Tile: `by <creator>` (link if `creatorUrl`; "probably by" if inferred) + badge pill + "No AI" chip.
- `Details.svelte` (exactly one selected): creator, creator link, license (text or URL), copyright notice, read-only sources ("from the page", "from the file", "you edited this"), source page link; Save calls `applyUserEdit` then `setCredit`.
- Search haystack adds creator and license label. Zip: `CREDITS.md` replaces `sources.txt`; the toggle reads "with credits".
- Tests: `buildCreditsMd` (known/unknown/edited) in zip tests; search by creator.

### Task 8: Privacy, e2e, screenshots

- e2e fixtures: page with JSON-LD ImageObject (CC BY 4.0, creator), page with `rel=license` CC BY-NC, NoAI page, JPEG with an injected XMP APP1 segment. Checks: badges and creator shown, the details edit persists, CREDITS.md content, Keep all blocked on the NoAI page and the worker refuses.
