# moodoodle v1.2 Plan C: Find similar (orbit overlay, on-device)

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. TDD per task (pure logic in Vitest; model + overlay via e2e).

**Goal:** "Find similar" opens an orbit overlay on the current page (or in the gallery): the chosen image at the
center, up to 6 look-alikes **from your saves** orbiting it. Matching runs on-device with a bundled image model;
nothing leaves the browser. "Open in Google Lens ↗" stays as a link.

**Spike findings (2026-10-08, Chromium headless):** `Xenova/dinov2-small` q8 (24 MB, Apache-2.0) via
Transformers.js 4.3.1 runs in an **offscreen document** (service workers can't `import()` the ONNX runtime glue).
It needs the extension-pages CSP `script-src 'self' 'wasm-unsafe-eval'` and only the
`ort-wasm-simd-threaded.asyncify` runtime. Load ~1.9 s, embed ~1.4 s. The embedding is the CLS token: the first
384 values of `last_hidden_state` [1, 257, 384]. `pool: true` is unsupported for this model.

**Spec:** `docs/specs/2026-10-07-boards-and-credits.md` §11 (inner ring only; web ring parked).

## Global Constraints
- Model and runtime are bundled (`public/models/…`, ORT asyncify wasm through Vite `?url`); `env.allowRemoteModels = false`. No CDN, no remote code.
- New permission: `offscreen` (no install warning). CSP adds `'wasm-unsafe-eval'` for bundled WebAssembly only.
- Embeddings are L2-normalized Float32Array(384), stored per image id with `model: 'dinov2-small-q8'`.
- Show at most 6 results with cosine ≥ 0.25; never include the query image itself.
- Respect `prefers-reduced-motion` (no rotation). Close with ×, Esc or a backdrop click. All controls are real buttons.

## Review Focus
1. **First run after the update:** existing images have no embeddings; the overlay says "Still learning your collection…" and backfill runs in the background (Task 3).
2. **Find similar on an image you haven't kept:** embed it on the fly; it's not saved (Task 3).
3. **Only one or no other images:** the empty state, not an error (Task 4).
4. **The offscreen document already exists, or was closed by Chrome:** `ensureOffscreen` is idempotent (Task 3).
5. **Deleting an image** deletes its embedding, so it never appears as a result (Task 2).

## Tasks
1. **`src/lib/similar.ts`**: `normalize(v)`, `cosine(a, b)` (on normalized vectors), and
   `topSimilar(query, items: {id, vec}[], { k = 6, min = 0.25, exclude })`, sorted by score.
   Tests: identical vectors → 1, orthogonal → 0, ordering, the exclude id, the threshold, k.
2. **DB v4: `embeddings` store**: `setEmbedding(id, vec)`, `getEmbedding(id)`, `listEmbeddings()`,
   `missingEmbeddingIds()`; `remove()` also deletes the embedding. Tests incl. the v3 → v4 upgrade (images kept).
3. **Embedder plumbing**:
   - `offscreen/main.ts` (rewrite of the spike) handles `embed-image {id}`: read the thumb from IDB, embed, normalize, store. It also handles `embed-url {url}`, which returns the vector without storing.
   - `src/lib/embedder.ts` pulls out the CLS slice and normalization (unit-tested on fake tensors).
   - Worker: `ensureOffscreen()` (checks `runtime.getContexts`, creates with reason `WORKERS`); a sequential job queue; embed after each successful keep; backfill missing ids at startup and install.
   - Message `similar {imageUrl}` → `{ center, results: [{ image, thumb (data URL) }], learning, lensUrl }`.
   - Spike files (`e2e/spike-embed.mjs`, `public/ort`) are removed.
4. **Orbit overlay (`src/lib/orbit.ts`)**: a framework-free renderer `openOrbit(root: ShadowRoot | HTMLElement, data, handlers)`.
   - Dimmed backdrop; the center circle; up to 6 orbs on a ring with spokes; a rotating ring with counter-rotating orbs; pause on hover.
   - Clicking an orb shows a card (title, "by" creator, reuse badge, Show in gallery).
   - States: learning, empty ("Nothing like this in your saves yet"), loading. Esc / × / backdrop close.
   - jsdom tests: orb count = results (≤ 6), empty and learning text, card on click, Esc closes, reduced-motion class.
5. **Wire it up**:
   - The content script's **Similar** button opens the overlay (replacing the Lens tab).
   - The context menu "Find similar" sends `show-similar` to the tab.
   - The gallery's **Find similar** opens the same overlay.
   - "Show in gallery" opens `gallery.html?focus=<id>`, which selects that image.
   - The Lens link stays inside the overlay.
6. **E2E + docs**:
   - e2e: after keeps, the embeddings exist; `similar` returns ≤ 6 results, never the query; the overlay renders orbs and closes on Esc; with a single image it shows the empty state.
   - Privacy policy: on-device matching, nothing sent. Store listing: `offscreen` justification and size.
   - Regenerate the screenshots.
